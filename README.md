## About

Live Better Games is an independent digital entertainment and creator platform developed by LiveaBetterLife under Live Better Studios.

Our mission is to provide a home for original games, independent animation, movies, music, digital art, and creative projects from creators around the world.

Inspired by the freedom and creativity of the independent internet, Live Better Games combines browser-based entertainment, creative discovery, and creator publishing into one unified platform.

We believe that ideas deserve to become reality.

## Our Vision

Live Better Games is being developed as a platform where creators can:

- Create and publish original projects.
- Share their games, music, artwork, movies, and other creative content.
- Build a creator profile and connect with audiences.
- Manage, update, and distribute their work.
- Discover other independent creators and their projects.
- Eventually participate in secure, verified creator monetization opportunities.

Our goal is to build more than a game website. We are building a creative ecosystem.

## Platform Features

### Discovery and Entertainment

- Browser-based HTML5 games.
- Independent movies and animation.
- Digital artwork and galleries.
- Music and audio projects.
- Content categories and search.
- Favorites and creator discovery.
- Responsive desktop and mobile interfaces.
- Original Live Better Games arcade-inspired design.

### Creator Publishing

The publishing system is being developed to support:

- Real creator accounts and authentication.
- Online creator dashboards.
- Game uploads using HTML or ZIP archives.
- Music, artwork, and video uploads.
- Project titles, descriptions, thumbnails, and screenshots.
- Drafts and private previews.
- Publishing and unpublishing.
- Updating existing projects without changing website source code.
- Persistent online project storage.

### Security and Trust

Platform security is a core development priority.

The publishing architecture includes or is designed to support:

- Secure authentication and account permissions.
- Persistent hosted database storage.
- Server-side upload validation.
- Safe archive extraction.
- Isolated execution of uploaded browser games.
- Creator ownership verification.
- Administrative publishing controls.
- Content moderation and reporting.
- Protection of private data and infrastructure credentials.

Public third-party uploads will not be enabled until the appropriate security, moderation, and malware protection requirements have been implemented and verified.

## Current Development Status

**Status: Active development — online publishing integration.**

The original Live Better Games website design and existing entertainment features are established.

The cloud publishing implementation and deployment configuration have been prepared.

The next milestone is connecting the hosted infrastructure, deploying the publishing system online, and verifying the complete creator workflow using independent devices.

Live deployment, cross-device upload verification, and unrestricted public creator registration are not yet complete.

## Technology

The project uses technologies appropriate to its actual requirements, including:

- HTML5
- CSS3
- JavaScript
- Python / Flask backend
- PostgreSQL
- Hosted persistent file storage
- Secure HTTPS deployment
- GitHub source control
- Render cloud deployment configuration

The platform's online services are separate from the internal architecture of individual games.

Standalone single-player games do not require networking, online accounts, or cloud saves unless those features are part of their intended design.

## Development and Deployment Standards

Live Better Games follows the LiveBetterStudios Universal AI Master Development Prompt.

Core requirements:

1. Preserve completed designs and existing functionality.
2. Select architecture intelligently based on actual project requirements.
3. Implement real functionality rather than simulated substitutes.
4. Use genuine hosted services for features requiring online accounts, uploads, and shared data.
5. Preserve offline-capable gameplay where networking is unnecessary.
6. Verify security, persistence, and functionality before claiming completion.
7. Test online publishing workflows through an actual internet-accessible deployment.
8. Confirm shared online functionality across independent devices.
9. Continue development through verified release milestones.

A local prototype, successful compilation, or deployment package alone does not constitute a functioning online platform.
